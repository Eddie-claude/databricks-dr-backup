# v4.3 — E/S ADLS factorisées et logs loguru — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Supprimer les helpers d'E/S ADLS recopiés dans les notebooks au profit de `lib/uc_io.py`, et remplacer les `print` par le logger loguru du client, sans changer le comportement du backup ni de la restauration.

**Architecture:** Deux modules purs dans `lib/` reçoivent `spark`/`dbutils` en paramètre (Databricks ne les injecte que dans les notebooks). Prérequis : `lib_path` doit pointer vers le `lib/` déployé par le bundle, sinon tout nouveau module de `lib/` casse les jobs (constat du 2026-10-07, voir la spec). loguru est installé comme bibliothèque PyPI de tâche, avec un repli `logging` pour les exécutions hors job.

**Tech Stack:** Python 3.12 (DBR 17.3 LTS), PySpark, Databricks Asset Bundles, loguru 0.7.3, pytest.

**Spec:** `docs/superpowers/specs/2026-10-07-v4.3-uc-io-loguru-design.md`

## Global Constraints

- loguru : `loguru==0.7.3` exactement, partout (`databricks.yml`, `requirements.txt`).
- Format de log : celui du client, à l'identique — `<cyan>{time:YYYY-MM-DD HH:mm:ss}</cyan> | <level>{level:<8}</level> | <green>{name}</green> | <blue>{function}</blue>:<yellow>{line}</yellow> | {message}`, sur `sys.stderr`, `colorize=True`.
- Modules de `lib/` : aucune importation `lib.xxx` entre modules (les notebooks importent `uc_io`, les tests `lib.uc_io`), aucun effet de bord à l'import, aucune variable globale `spark`/`dbutils`.
- Pas de changement de comportement hors Task 1 : mêmes chemins ADLS écrits, mêmes formats de fichiers, mêmes messages (seuls le préfixe `[XXX]` et l'horodatage manuel disparaissent au profit du format du logger).
- Messages en français, comme l'existant.
- **Aucun `git push` avant la validation complète sur dev (Task 7)** : chaque push redéploie le workspace KeyIT via GitHub Actions. Toute écriture sur le workspace dev demande l'accord explicite de l'utilisateur.
- Les blocs de notebook entre marqueurs `# >>> XXX` / `# <<< XXX` sont extraits et exécutés seuls par les tests (`tests/test_data_clone_rules.py`, `test_grants_export.py`, `test_sync_grants.py`, `test_coverage_*.py`) : ils ne doivent référencer ni `logger`, ni `uc_files`, ni `short_error`.
- Scripts de patch : les écrire avec l'outil Write, jamais via un heredoc bash (`python - <<'EOF'` altère les `\n`).
- Réseau du poste instable vers Databricks : relancer une commande CLI qui échoue sur EOF/timeout avant de conclure. Sous Git Bash, préfixer les commandes `databricks workspace` par `MSYS_NO_PATHCONV=1`.

```python
    """dbutils.fs minimal : fichiers à plat, dossiers implicites, mêmes erreurs que le vrai."""

    def __init__(self):
        self.files = {}
        self.calls = []

    def head(self, path, max_bytes):
        self.calls.append(("head", path, max_bytes))
        if path not in self.files:
            raise FileNotFoundError(path)
        return self.files[path][:max_bytes]

    def ls(self, directory):
        prefix = directory.rstrip("/") + "/"
        names = sorted({p[len(prefix):].split("/")[0] for p in self.files if p.startswith(prefix)})
        if not names:
            raise FileNotFoundError(directory)
        return [SimpleNamespace(path=prefix + n, name=n) for n in names]

    def rm(self, path, recurse=False):
        keys = [p for p in self.files if p == path or p.startswith(path.rstrip("/") + "/")]
        if not keys:
            raise FileNotFoundError(path)
        if not recurse and keys != [path]:
            raise IsADirectoryError(path)
        for k in keys:
            del self.files[k]

    def mv(self, src, dst):
        self.files[dst] = self.files.pop(src)
```

```python
# lib/uc_io.py
"""Lecture / écriture de petits fichiers texte (JSON, SQL, manifests) sur ADLS.

dbutils.fs.put/head contournent les External Locations Unity Catalog et exigent une clé ABFS
sur le cluster : l'écriture passe donc par Spark, qui utilise les credentials UC.

La lecture passe par dbutils.fs.head et non par spark.read.text : ce dernier a montré un cache
de listing par chemin qui survit à une réécriture complète du fichier dans la même session
(« Bytes read: 0 B », commit 199aef1).

spark et dbutils sont reçus en paramètre : Databricks ne les injecte que dans les notebooks,
pas dans les modules importés via sys.path.
"""

HEAD_MAX_BYTES = 10_000_000


class UcIO:
    def __init__(self, spark, dbutils):
        self._spark = spark
        self._fs = dbutils.fs

    def head(self, path: str) -> str:
        return self._fs.head(path, HEAD_MAX_BYTES)

    def put(self, path: str, content: str) -> None:
        """Écrit content dans path (écrase) : Spark écrit un dossier temporaire, on en garde la part."""
        tmp = path + ".__tmp__"
        try:
            self._fs.rm(tmp, recurse=True)
        except Exception:
            pass
        self._spark.createDataFrame([(line,) for line in content.split("\n")], "value STRING") \
            .coalesce(1).write.mode("overwrite").text(tmp)
        parts = [f.path for f in self._fs.ls(tmp)
                 if not f.name.startswith("_") and not f.name.startswith(".")]
        try:
            self._fs.rm(path)
        except Exception:
            pass
        self._fs.mv(parts[0], path)
        self._fs.rm(tmp, recurse=True)

    def read_text(self, path: str) -> str:
        """Lecture via Spark, pour les fichiers au-delà de HEAD_MAX_BYTES (sources de notebooks).

        Sujet au cache de listing de spark.read.text : ne pas l'utiliser sur un fichier réécrit
        dans la même session.
        """
        try:
            return "\n".join(r.value for r in self._spark.read.text(path).collect())
        except Exception as e:
            raise RuntimeError(f"Impossible de lire {path}: {e}")
```

```python
# lib/logger.py
"""Logger commun du projet : configuration loguru identique aux autres repos du client.

loguru est installé comme bibliothèque des tâches de job (databricks.yml). Une restauration
lancée à la main sur un cluster qui ne l'a pas, ou un script local sans requirements.txt,
bascule sur le module logging : même format sans couleurs, mêmes méthodes. Une bibliothèque de
logs ne doit jamais empêcher une restauration de tourner.

Usage : appels en f-string, sans argument positionnel — loguru ne formate pas un message passé
seul, les accolades des données (JSON, DDL) sont donc sans danger.
"""
import logging
import sys

try:
    from loguru import logger as _loguru
except ImportError:
    _loguru = None

# https://loguru.readthedocs.io/en/stable/api/logger.html
FORMAT = ("<cyan>{time:YYYY-MM-DD HH:mm:ss}</cyan> | <level>{level:<8}</level> | "
          "<green>{name}</green> | <blue>{function}</blue>:<yellow>{line}</yellow> | {message}")
_FALLBACK_FORMAT = "%(asctime)s | %(levelname)-8s | %(name)s | %(funcName)s:%(lineno)d | %(message)s"
_SUCCESS = 25
logging.addLevelName(_SUCCESS, "SUCCESS")


class _StdlibLogger:
    """Expose sur logging les méthodes loguru utilisées par le projet."""

    def __init__(self, base: logging.Logger):
        self._base = base

    # stacklevel=2 : funcName/lineno désignent l'appelant, pas cette classe
    def debug(self, msg: str) -> None:
        self._base.debug(msg, stacklevel=2)

    def info(self, msg: str) -> None:
        self._base.info(msg, stacklevel=2)

    def success(self, msg: str) -> None:
        self._base.log(_SUCCESS, msg, stacklevel=2)

    def warning(self, msg: str) -> None:
        self._base.warning(msg, stacklevel=2)

    def error(self, msg: str) -> None:
        self._base.error(msg, stacklevel=2)

    def exception(self, msg: str) -> None:
        self._base.exception(msg, stacklevel=2)


def create_logger(level: str = "INFO"):
    """Create a logger with a custom format."""
    if _loguru is not None:
        _loguru.remove()  # remove then replace with custom handler below
        _loguru.add(sys.stderr, level=level, colorize=True, format=FORMAT)
        return _loguru
    base = logging.getLogger("dr_backup")
    base.handlers.clear()
    handler = logging.StreamHandler(sys.stderr)
    handler.setFormatter(logging.Formatter(_FALLBACK_FORMAT, "%Y-%m-%d %H:%M:%S"))
    base.addHandler(handler)
    base.setLevel(level)
    base.propagate = False
    base.warning("loguru indisponible — repli sur le module logging (même format, sans couleurs)")
    return _StdlibLogger(base)


def short_error(e, limit: int = 300) -> str:
    """Première partie de l'erreur sur une ligne : les exceptions Spark embarquent une stacktrace
    JVM de centaines de lignes qui fait dépasser la limite de sortie du notebook."""
    return " ".join(str(e).split("JVM stacktrace:")[0].split())[:limit]
```

```python
"""Convertit les print à étiquette en appels logger ; liste ce qui reste à traiter à la main."""
import re
import sys

RULES = [
    (r'print\((f?)"\s*\[OK\]\s*', r'logger.success(\1"'),
    (r'print\((f?)"\s*✓\s*', r'logger.success(\1"'),
    (r'print\((f?)"\s*\[INFO\]\s*', r'logger.info(\1"'),
    (r'print\((f?)"\s*\[WARN\]\s*', r'logger.warning(\1"'),
    (r'print\((f?)"\s*\[ERROR\]\s*', r'logger.error(\1"'),
    (r'print\((f?)"\s*✗\s*ERREUR\s*', r'logger.error(\1"'),
    (r'print\((f?)"\s*\[(SKIP|AUTO|RESUME)\]', r'logger.info(\1"[\2]'),
]

for path in sys.argv[1:]:
    with open(path, encoding="utf-8") as f:
        src = f.read()
    for pattern, repl in RULES:
        src = re.sub(pattern, repl, src)
    with open(path, "w", encoding="utf-8", newline="") as f:
        f.write(src)
    left = [(i, l.strip()) for i, l in enumerate(src.splitlines(), 1) if re.match(r"\s*print\(", l)]
    print(f"== {path} : {len(left)} print restants")
    for i, l in left:
        print(f"  {i}: {l[:110]}")
```
